# Roadmap

These are **ideas under consideration**, not commitments, timelines, or
announced plugins. None of the following are implemented in this
marketplace today.

- Sheth PDF & Document Tools
- Sheth Data Engineering
- Sheth Data Science
- Sheth AI Media
- Sheth Architecture
- Sheth Project Management
- Sheth Recruitment

A future plugin idea moves from this list into an actual plugin by
following `docs/adding-a-plugin.md`, including full skills, tests, and
changelog entries — not by being added here.
