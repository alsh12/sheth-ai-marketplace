# Changelog

All notable changes to the Sheth Developer Tools plugin are documented here.

## 1.0.0 - Initial release

- `json-formatter`: pretty-print/minify JSON without altering data.
- `json-validator`: JSON syntax validation with located, explained errors.
- `xml-formatter`: indent XML while preserving namespaces, comments, and
  processing instructions.
- `xml-validator`: XML well-formedness checking, with optional validation
  against a user-supplied DTD or XML Schema.
- `json-xml-converter`: bidirectional JSON/XML conversion with explicit
  mapping-convention and lossy-conversion reporting.
