# Changelog

All notable changes to the Sheth Engineering plugin are documented here.

## 1.0.0 - Initial release

- `dotnet-development`: convention-respecting C#/.NET application code,
  covering ASP.NET Core, DI, async, and EF Core.
- `python-development`: typed Python application code with explicit
  exception handling, logging, and minimal dependencies.
- `api-development`: REST API design/implementation covering validation,
  auth, errors, pagination, versioning, idempotency, and rate limiting.
- `test-development`: deterministic, isolated test writing with
  run-verified pass/fail reporting.
- `debugging`: evidence-based bug diagnosis, minimal verified fix, and
  regression test.
