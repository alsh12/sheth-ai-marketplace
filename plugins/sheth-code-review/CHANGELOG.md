# Changelog

All notable changes to the Sheth Code Review plugin are documented here.

## 1.0.0 - Initial release

- `code-review`: severity-ranked general correctness and regression review.
- `security-review`: category-based security weakness review (auth,
  injection, secrets, deserialization, dependency risk) without claiming
  exhaustive coverage.
- `performance-review`: algorithmic/allocation/I-O review distinguishing
  measured from theoretical impact.
- `pull-request-review`: requirements-based PR review with a blocking /
  non-blocking summary.
